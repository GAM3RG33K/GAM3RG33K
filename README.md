## About Me

Engineer with **9 years** shipping full-stack products in fintech and creator economy (apps at **350k+ downloads**), now focused on **AI platform work: agent harnesses, evals, and tooling**.

Built a **custom AI harness + harness generator** used across my projects and job codebases (Tatva, Meme'd, Solo), `pixel-press` with on-device LLM inference, and `mcp-harshjoshi-work`, an MCP server with an eval harness.

- 🔭 Currently shipping **[pixel-press](https://github.com/GAM3RG33K/pixel-press)** — local-first, offline desktop video compressor; on-device LLM (llama.cpp, SmolLM2-360M) turns plain-language intent into FFmpeg plans.
- 🛠️ Built **[mcp-harshjoshi-work](https://github.com/GAM3RG33K/mcp-harshjoshi-work)** — MCP server exposing my project catalog and profile as searchable tools; 6-case eval harness.
- 📋 Created **Custom AI Harness + Harness Generator** — reusable agent-SDLC rules system for undocumented projects (`.ai/rules/`, plan scoring, verification gates, decision writeback).
- 🛠️ Open-source agent skills — **[omniframe](https://github.com/GAM3RG33K/omniframe)**, **[git-what](https://github.com/GAM3RG33K/git-what)**, **[react-native-performance-analyzer](https://github.com/GAM3RG33K/react-native-performance-analyzer)**.
- ⚡ Automation win: cut mobile delivery time **87.5%** at Signzy through CI/CD and build automation. Lead a 5-person full-stack pod; ran hiring end to end.
